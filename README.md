## Fitur Utama
1. **Interactive Terminal CLI:** Kotak terminal interaktif di mana pengguna dapat mengetik perintah (`help`, `about`, `features`, `clear`).
2. **Matrix Hacker Background:** Efek latar belakang animasi digital hujan kode hijau yang dinamis.
3. **Monochrome Green Theme:** Desain estetika minimalis tanpa banyak warna, fokus pada kontras gelap dan hijau terang khas terminal sistem.

## Cara Menjalankan
1. Clone repositori ini atau unduh semua file (`index.html`, `style.css`, `script.js`, `README.md`) ke dalam satu folder.
2. Buka `index.html` menggunakan browser atau gunakan *Live Server* di VS Code.
